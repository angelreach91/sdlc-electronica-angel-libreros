# Segunda revisión por pares — Semana 3

Este Pull Request se abre para realizar una nueva revisión de la API SensorHub utilizando la checklist oficial de 10 puntos.

La revisión debe aplicarse al código completo ubicado en `app/`, no únicamente al archivo modificado en este Pull Request.

## Instrucciones para el revisor

1. Descargar y ejecutar la rama del Pull Request.
2. Levantar la aplicación y comprobar Swagger.
3. Ejecutar Pytest, Ruff y Mypy.
4. Revisar la API mediante los 10 puntos de la checklist.
5. Dejar mínimo dos observaciones específicas con formato `archivo:línea`.
6. Dejar mínimo una pregunta sobre una decisión de diseño.
7. Declarar uno de los siguientes veredictos:
   - Aprobado.
   - Aprobado con cambios.
   - Solicito cambios.

Las observaciones pueden colocarse en la sección `Conversation` del Pull Request, indicando claramente el archivo y la línea revisada.
